# GitHub Copilot Configuration

This directory contains configuration for GitHub Copilot.

## Setup Instructions

### For VS Code/Cursor
1. Install the GitHub Copilot extension
2. Sign in with your GitHub account
3. Settings are included in the Cursor/VS Code settings.json

### For JetBrains IDEs (Rider)
1. Install GitHub Copilot plugin from the marketplace
2. Go to Settings → Tools → GitHub Copilot
3. Sign in with your GitHub account
4. Enable suggestions

### For Zed
1. GitHub Copilot is enabled via the settings.json
2. You may need to authenticate via command palette
3. Use `cmd/ctrl + shift + p` → "Copilot: Sign In"

## Configuration Options

The following settings are recommended:
- Enable inline suggestions
- Enable chat features (where available)
- Configure language-specific settings as needed

## Privacy
- Telemetry is disabled by default in editor configurations
- Review GitHub Copilot privacy settings at: https://github.com/settings/copilot
